# 🚀 Muhammad Abdul Rehman — AI & ML Developer Portfolio

A modern, high-performance, interactive portfolio website showcasing projects in **RAG Systems**, **Local LLMs**, **Computer Vision**, **Data Science**, and **Intelligent Automation**.

Built with **React 19**, **Vite 8**, **TailwindCSS 4**, and **TypeScript**.

---

## ✨ Key Features

- **⚡ Modern High-Contrast Aesthetics**: Cyberpunk-inspired dark theme with gold accenting and a high-contrast Light Mode toggle.
- **📄 Interactive CV Viewer**: Full-screen document viewer modal with high-resolution preview and instant PDF download.
- **📜 Verified Certificate Lightbox**: Interactive full-screen certificate modal with verification badges and direct image downloads.
- **🎨 Interactive Visuals**: Dynamic Matrix Rain hero canvas and interactive Neural Network graph with animated data nodes.
- **🔍 Filterable Portfolio**: Category-based project filtering (*All, AI & RAG, Computer Vision, Systems & Automation, Data Science*) with animated tabs.
- **🎓 Standalone Sections**: Cleanly organized sections for **About**, **Skills**, **Experience**, **Projects**, **Education**, **Certifications & Leadership**, and **Contact**.
- **📱 Fully Responsive**: Hamburger navigation menu, touch-optimized cards, and mobile-friendly layouts.

---

## 🛠️ Tech Stack

- **Frontend Core**: React 19, TypeScript
- **Bundler & Tooling**: Vite 8, TailwindCSS 4, `@tailwindcss/vite`
- **Typography**: Google Fonts (*Orbitron, Outfit, JetBrains Mono*)

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18 or higher) installed on your system.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mabdulrehman-CS/Portfolio-Website.git
   cd Portfolio-Website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

## 📜 Available Scripts

| Command | Description |
